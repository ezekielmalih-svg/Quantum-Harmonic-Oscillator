# Quantum Harmonic Oscillator

This project explores the quantum mechanical harmonic oscillator using Python and symbolic computation with SymPy.

The notebook was developed as part of my coursework in the Erasmus Mundus Master's programme in Theoretical Chemistry and Computational Modelling (TCCM).

## Topics Covered

- Quantum harmonic oscillator potential
- Analytical energy levels
- Hermite polynomials
- Harmonic oscillator wavefunctions
- Symbolic verification of the Schrödinger equation
- Wavefunction normalization
- Expectation values
- Identification and visualization of wavefunction nodes
- Visualization of wavefunctions and energy levels

## Tools

- Python
- SymPy
- NumPy
- Matplotlib
- Jupyter Notebook

## Notebook

The main notebook is:

`Harmonic_Oscillator.ipynb`

It contains the Python implementation, symbolic calculations, numerical results, and visualizations.

## Context

This work was completed as a computational physical chemistry coursework project. The original project framework was provided through the pyPhysChem teaching materials, while the calculations and exercises presented in the completed notebook were carried out as part of my coursework.
